# PHILOSOPHY ACADEMY

**哲学思维与思想探索学习平台** · Explore Ideas. Question Everything. Think Independently.

一套以三本著作为核心教材、以独立思考和逻辑论证能力培养为目标的个人哲学学习平台。不是知识百科，而是让你从哲学知识的阅读者，逐渐成为能独立提问、分析和论证的思考者。

## 核心教材

| 教材 | 作者 | 在本平台的角色 |
| --- | --- | --- |
| 《大问题：简明哲学导论》 | Robert C. Solomon / Kathleen M. Higgins | 核心教材，建立知识体系 |
| 《西方哲学简史（修订版）》 | 赵敦华 | 思想发展史脉络，思想家档案 |
| 《做哲学：88个思想实验中的哲学导论》 | 小西奥多·希克 / 刘易斯·沃恩 | 思辨训练，思想实验实验室 |

课程内容依据三本书的真实章节组织，用平台自己的语言重新编写，并明确标注教材来源与平台扩展内容；不虚构原书章节、页码或原文。

## 功能模块

- **八大课程模块**：哲学入门 / 认识论 / 形而上学 / 伦理学 / 政治哲学 / 心灵与人生哲学 / 逻辑与批判性思维 / 思想实验方法论。每章采用统一的十段式结构（学习目标→核心问题→关键概念→哲学理论→代表性哲学家→经典论证→现实案例→思考练习→本章总结→章节测验）。
- **思想实验实验室**（核心特色）：多个哲学情境，选择立场→给出理由→分析你使用的原则、隐含前提与逻辑漏洞→逐层追问。不给标准答案。
- **四种思辨训练**：每日哲学问题、论证分析训练、立场辩论（按论证质量评分而非立场）、哲学写作（草稿+版本记录）。
- **知识库**：思想家档案（含思想传承关系）、可检索概念词典、思想关系图谱与历史时间线。
- **学习系统**：进度追踪、章节测验、错题本、笔记、收藏、写作积累、学习历史、连续天数，全部本地持久化。

## 技术栈

React + TypeScript + Vite + Tailwind CSS + Lucide Icons。纯静态站，无需后端。用户学习数据存于浏览器 LocalStorage，与课程内容分离，预留云端同步接口。

## 本地运行

```bash
npm install
npm run dev        # 开发预览
npm run build      # 构建到 dist/
npm run preview    # 预览构建产物
```

## 部署到 GitHub Pages

已配置相对路径构建（`base: './'`），构建产物可放在仓库根目录或任意子目录，`/<仓库名>/` 子路径下也能正常访问。

### 方式一：GitHub Actions 自动部署（推荐）

项目已内置 `.github/workflows/deploy.yml`。

1. 把代码推送到 GitHub 仓库的 `main` 或 `master` 分支
2. 在仓库 **Settings → Pages → Build and deployment** 中，Source 选择 **GitHub Actions**
3. 之后每次 push 都会自动构建并部署，无需手动操作

### 方式二：手动部署

```bash
npm run build            # 产物在 dist/
```

把 `dist/` 的内容推送到仓库（可用 `gh-pages` 分支，或仓库 `docs/` 目录后在 Settings → Pages 中选择对应来源）。

### 关于路由

站点使用 HashRouter（URL 形如 `/#/course/m1`），因此刷新任意页面、部署在任意子路径都不会 404，无需额外配置。

## 数据说明

所有学习记录保存在本机浏览器。可在「我的 → 设置」中导出数据备份或清空。清除浏览器数据会导致记录丢失，建议定期导出备份。
